**ක්‍රියාකාරී බලපෑම**: සමහර ශ්‍රිත පද්ධතියේ ක්‍රියාකාරිත්වයට බලපෑ හැකිය. යෙදවීමට පෙර සෑම සැකසුමක්ම සැලකිලිමත්ව සමාලෝචනය කරන්න.

## 🔍 ශ්‍රිත විස්තර

### ප්‍රධාන ශක්තිමත් කිරීමේ ශ්‍රිත

#### ජාල සේවා
- **RDP**: දුරස්ථ ඩෙස්ක්ටොප් ප්‍රවේශය අවහිර කරයි හෝ port අහඹු කරයි
- **SMBv1**: ලෙගසි ගොනු බෙදාගැනීමේ ප්‍රොටෝකෝලය අක්‍රීය කරයි
- **ICMP**: ඔත්තු බැලීම සඳහා ping ප්‍රතිචාර වළක්වයි
- **LLMNR/NetBIOS**: ලෙගසි නාම විභේදන ප්‍රොටෝකෝල අවහිර කරයි

#### යෙදුම් ආරක්ෂණය
- **මැක්‍රෝ**: Office යෙදුම්වල මැක්‍රෝ ක්‍රියාත්මක කිරීම අක්‍රීය කරයි
- **AutoRun**: ඉවත් කළ හැකි මාධ්‍යයන්ගෙන් ස්වයංක්‍රීය ක්‍රියාත්මක කිරීම වළක්වයි

#### දුරස්ථ කළමනාකරණය
- **PSRemoting**: PowerShell දුරස්ථ සැසි අක්‍රීය කරයි
- **WinRM**: Windows Remote Management නවත්වයි
- **Remote Assistance**: දුරස්ථ සහාය සම්බන්ධතා අවහිර කරයි

#### ප්‍රවේශ පාලනය
- **Admin Shares**: C$, ADMIN$ බෙදාගැනීම් අක්‍රීය කරයි
- **Guest Account**: අමුත්තන්ගේ ගිණුම් ප්‍රවේශය අක්‍රීය කරයි
- **USB Storage**: USB උපාංග භාවිතය සීමා කරයි

## ⚠️ වැදගත් සලකා බැලීම්

### පරීක්ෂණ අවශ්‍යතා
- **පර්යේෂණාගාර පරිසරය**: මුලින්ම සියලු සැකසුම් හුදකලා පරිසරයේ පරීක්ෂා කරන්න
- **අදියර අදියරට යෙදවීම**: ගැටලු හඳුනා ගැනීමට ක්‍රමයෙන් rollout කරන්න
- **rollback සැලැස්ම**: අවශ්‍ය නම් වෙනස්කම් අහෝසි කළ හැකි බව සහතික කරන්න
- **ලියකියවිලි**: ඔබේ පරිසරය සඳහා සේ සැකසුම් ක්‍රියා කරන්නේද යන්න වාර්තා කරන්න

### විභව බලපෑම
- **භාවිතාකරුවාගේ ඵලදායිතාව**: සමහර සැකසුම් දෛනික කාර්ය ප්‍රවාහයන්ට බලපෑ හැක
- **ලෙගසි යෙදුම්**: පැරණි පද්ධතිවලට විශේෂිත ප්‍රොටෝකෝල අවශ්‍ය විය හැක
- **දුරස්ථ ප්‍රවේශය**: නීත්‍යානුකූල දුරස්ථ පරිපාලනයට ඇති බලපෑම සලකා බලන්න
- **ව්‍යාපාරික ක්‍රියාවලි**: සැකසුම් තීරණාත්මක ශ්‍රිත බිඳ නොදක්වන බව තහවුරු කරන්න

### ආරක්ෂණ සීමාවන්
- **ගැඹුරු ආරක්ෂණය**: Ghost ආරක්ෂණ ස්ථරයක්, සම්පූර්ණ විසඳුමක් නොවේ
- **අඛණ්ඩ කළමනාකරණය**: ආරක්ෂණයට අඛණ්ඩ අධීක්ෂණය සහ යාවත්කාලීන අවශ්‍ය
- **භාවිතාකරුවාගේ පුහුණුව**: තාක්ෂණික පාලනය ආරක්ෂණ දැනුවත්භාවය සමඟ යුගල විය යුතුය
- **තර්ජන පරිණාමය**: නව ප්‍රහාරක ක්‍රම වර්තමාන ආරක්ෂණ මඟහරවා ගත හැක

## 🎯ප්‍රහාරක අවස්ථා උදාහරණ

Ghost සාමාන්‍ය ප්‍රහාරක දෛශික ඉලක්ක කරගත් ද, නිශ්චිත වැළැක්වීම නියමිත ක්‍රියාත්මක කිරීම සහ පරීක්ෂණ මත රඳා පවතී:

### WannaCry ශෛලියේ ප්‍රහාර
- **සමනය**: `Set-Ghost -SMBv1` දුර්වල ප්‍රොටෝකෝලය අක්‍රීය කරයි
- **සලකා බැලීම්**: කිසිදු ලෙගසි පද්ධතියකට SMBv1 අවශ්‍ය නොවන බව සහතික කරන්න

### RDP පදනම් කරගත් Ransomware
- **සමනය**: `Set-Ghost -RDP` දුරස්ථ ඩෙස්ක්ටොප් ප්‍රවේශය අවහිර කරයි
- **සලකා බැලීම්**: විකල්ප දුරස්ථ ප්‍රවේශ ක්‍රම අවශ්‍ය විය හැක

### ලේඛන පදනම් කරගත් අනිෂ්ට මෘදුකාංග
- **සමනය**: `Set-Ghost -Macros` මැක්‍රෝ ක්‍රියාත්මක කිරීම අක්‍රීය කරයි
- **සලකා බැලීම්**: නීත්‍යානුකූල මැක්‍රෝ-සක්‍රීය ලේඛනවලට බලපෑ හැක

### USB සම්ප්‍රේෂණය කළ තර්ජන
- **සමනය**: `Set-Ghost -USBStorage -AutoRun` USB ක්‍රියාකාරිත්වය සීමා කරයි
- **සලකා බැලීම්**: නීත්‍යානුකූල USB උපාංග භාවිතයට බලපෑ හැක
